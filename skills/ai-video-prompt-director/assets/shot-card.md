# 镜头卡与提示词模板

按实际任务删减栏目。下面的填空是工作模板，不能带着未填项交付为“可直接生成版”。

## 制作信息（不粘进生成正文）

- 镜头 / 生成任务编号：
- 本段叙事目的：
- 工具、入口、模型、输入模式及核验日期：
- 建议生成长度 / 最终目标长度 / 画幅：
- 源片范围（仅复刻任务）：
- 最终剪辑位置（需要音乐卡点时）：
- 观察事实 / 推断 / 创作选择：

## 参考绑定

|实际文件|用途|控制的内容|不继承的内容或冲突|真实界面标签|
|---|---|---|---|---|
|填写已存在文件|身份/起点/终点/空间/运动/音频|明确分工|没有则删栏|未绑定则写待绑定|

没有素材时删除这张表，不虚构图片或视频。

## 状态与路径草稿

- 固定约定：本段必须稳定的身份、服装、道具和空间关系。
- 开头：景别、机位、画面位置、主体姿态、物体状态。
- 过程：主体动作；相机路径；环境或物体变化。注明先后，避免混写。
- 转场：触发物 → 遮挡/匹配方式 → 落地构图。没有转场就删除。
- 结束：本任务最后可见状态；哪些内容留给下一任务。
- 局部约束：最容易出错的少量具体关系。

## 可复制生成正文

[本段必要视觉锚点与起始构图]。[主体做什么]，同时[相机如何移动/保持固定]。[随后可见的中间变化]。[结束构图和局部约束]。

多阶段且确需时间时改用本段 0 开始的时间窗。时间窗表达意图，不宣称帧级保证。正文不要夹入文件管理、来源说明、全片绝对时间或后期脚本参数。

## 单张参考图的提示词

[一个时刻的景别和机位]，[主体身份、姿态和画面位置]，[静态物体与空间关系]，[光色、材质和必要风格]。

每张只写一个时刻。多时刻分开成图，不在一张图里写连续动作。

## 后期与验收

- 音频来源、事件落点与证据类型：
- 必须由后期完成的切点、变速、文字或声音：
- 验收：核心事件、身份/空间、运动/终点、声音同步。
- 当前状态：提示词准备 / 已生成待检 / 已检及结果。
