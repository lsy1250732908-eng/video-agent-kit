# 视频创意简报

这是可选模板，不要求用户逐项填完。助手应先从已有对话填写；未知项标明假设或待确认。

- 一句话想法：
- 希望观众感到什么：
- 必须出现的画面/事件：
- 必须保持的角色、产品或关系：
- 可以自由发挥的部分：
- 明确不想要的效果：
- 时长 / 画幅 / 用途：
- 目标工具、入口和模型（已知才填）：
- 已有素材与用途：
- 音乐 / 对白 / 环境音 / 口型要求：
- 预算或尝试次数限制（需要实际生成时才填）：

## 意图优先级

|必须保留|可调整|待确认/假设|
|---|---|---|
|填写核心事件|填写装饰与可替代选择|写清会影响制作的未知项|

## 核心画面草稿

用一句可观察的句子说明：谁，在什么地方，经历什么变化，最后画面停在哪里。

## 验收依据

列出用户最在意的可见结果。没有成片前，结果状态统一为“未验证”。
