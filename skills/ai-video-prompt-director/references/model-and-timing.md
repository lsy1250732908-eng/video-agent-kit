# 工具适配、参考图与时间轴

## 先确定实际入口

记录“产品入口 + 模型/版本 + 输入模式 + 核对日期”，不要只写 Seedance。网页、API、第三方封装可能有不同的模式和限制。时长、分辨率、参考数量、上传类型和人脸素材能力属于会变化的信息，应在实际执行时核对官方说明或当前界面。

本技能不内置永久有效的 Seedance 秒数范围或未经核实的 API 参数。现有项目的 4—10 秒任务是历史项目配置。

若暂时无法核对，交付平台中立正文及明确标注的建议设置，不杜撰输入标签、参数或“已支持”功能。纯文本创意任务无需先做全平台调研。

|已确认的模式|提示词与素材重点|不足时如何调整|
|---|---|---|
|纯文生视频|清楚描述外形、空间、动作顺序，降低不必要的并行变化|身份难固定时建议先确定参考图；用户仅要文本仍交付文本版|
|单首帧|文字集中描述从此帧开始的变化，避免再次描述一个不同开场|终点和复杂路径用拆镜或后期控制|
|首尾帧|首尾状态可连接；正文描述中间如何到达|两张图无法单独说明绕行方向，必要时明确路径或改拆分|
|多图参考|给图片分配身份、布景、起止状态等用途，处理冲突|未确认支持中间帧控制时，不把普通参考图当硬关键帧|
|视频参考|说明继承动作、镜头还是节奏，以及哪些外观要换|视入口能力，不保证只替换指定一层|
|音频驱动/音频参考|确认它控制节奏、声音生成还是嘴形|不把能上传音频等同于能逐音素对口型|

工具调用只有在用户要求实际生成、且所需授权与工具可用时进行。写提示词本身不代表开始上传和消耗额度。

## 素材清单要能真正使用

对每个实际文件记录：文件名、用途、可见内容、冲突或局限、在目标入口的绑定标签。逻辑“图 1”与界面 `@...` 标签不是一回事。

若需要新图而用户只要求提示词，给一张图一个静态画面提示词和用途；若用户也要求生成参考图，再使用可用生图/编辑工具。没有生成的图片标注为“计划”，不返回虚构文件链接。

转场边界帧往往模糊：可以保留作切点证据，同时选择附近清晰图做身份/空间参考。清晰替代图不是原边界帧，记录其时间差，不能悄悄声称它精确对应首帧。

## 三套时间必须分开

- **源片时间 s**：参考原片中的位置，只在分析和来源表使用。
- **生成片段时间 g**：当前这条任务从 0 开始，写在生成正文中。
- **最终剪辑时间 e**：最终片里音乐与画面的绝对位置，写在剪辑表中。

设原片片段起点为 a，目标长度 D，建议生成长度 G。按均匀映射组织提示词：

`g = (s - a) × G / D`

如本项目 G05：a = 752/30 秒，D = 248/30 秒，G = 9 秒。原片 28.9 秒的庭院落点，对应生成段内约 4.173 秒。不能在 9 秒提示词里要求“28.9 秒进入庭院”。

如果实际模型输出长度为 L，初步回剪到 D 时：

- 时间戳乘数：D/L（例如 ffmpeg 的 setpts 概念）。
- 播放速度倍数：L/D。二者互为倒数，别混淆。
- 输出帧数优先按目标帧率计算，整数帧边界明确入点包含、出点不包含。

这是外部剪辑计算，不是提示词中的模型参数。实测输出长度 L 可能不同于建议 G。

## 为什么等长仍然不能保证卡点

例如一个 9 秒结果压回 8.267 秒后，总长正确，但刀刃闪光仍可能比音乐晚 0.3 秒。这是内部事件位置不同；整体匀速只能统一缩放，不能独立挪动一个动作。

处理顺序：

1. 实际看/听成片，在生成视频中标出事件时间，与最终目标比较。
2. 可隐藏的切点用剪辑移动；可接受的区间用分段变速或速度曲线。
3. 必须连续的主体动作，尝试更清楚的阶段顺序或补过程参考后局部重生成。
4. 若要求严格口型，按入口支持选择音频驱动或独立口型流程，完成后再检查。

分段变速可能损害动作自然度和嘴形，必须查看结果；不能写成无代价修复。

## 音乐不是提示词里的装饰词

“跟着节奏、踩点、很燃”不足以指定落点。记录具体视觉事件和对应音频时间，并标明声音依据：实际听辨、波形/起音检测、自动 BPM 候选，或用户指定。

本项目的 77.1/154.2 BPM 只属于该音轨的算法候选，没有人工定拍。新项目重新分析；不能继承这些数字，也不能由音量峰值直接断言是底鼓或小节首拍。

未获得音轨时可先写“第一次明确重音时抬头”等创作节奏草稿，并标记待对齐；不编造精确拍点。保留原音轨、生成环境音、录制对白或另做音乐由项目目标决定。
