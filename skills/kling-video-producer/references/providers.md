# Provider routes

Official entry: https://kling.ai/
Official MCP / CLI guide: https://kling.ai/app/mcp/guide

Check available tools and current documentation at execution time. Official MCP/CLI discovery was verified on 2026-11-12; their generation flow has NOT been tested by this project. Authentication, credits and capabilities may differ from the website. Do not invent tool names or assume web bonus credits apply.

Website fallback was exercised on one account: open the workbench, select a supported reference mode, upload through the visible First frame → Upload menu, confirm thumbnail and filename, enter prompt and check actual settings. Uploads may change aspect ratio to Adaptive. Do not hard-code models, prices, element IDs or waiting times.

For documented file-chooser APIs, start listening before clicking Upload and immediately handle rejection. Hidden-input clicks may time out. Read current tool documentation rather than copying arbitrary browser scripts.

On submission uncertainty inspect history before another submission. On Download locator ambiguity inspect the current DOM to select the actual button. Preserve task ID/link locally. Do not click community Publish as part of generation/download.

A single website case is evidence for the workflow, not a guarantee across accounts or future versions. The local CLI manages records only; an agent or user operates the provider.
